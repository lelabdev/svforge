Dashboard is now generated by the **canonical Base delivery** instead of replaying a filtered copy of the Base file map: `deliverBaseScaffold()` delivers the shared dependency declarations, project wiring, template/root files and vendored docs once, with explicit exclusions for the files the official Better Auth/Drizzle add-ons own and for the Dashboard-owned Vitest config. The Dashboard overlay then only adds its capabilities, and the upgrade baseline is computed once from the final delivered map. Generated output is unchanged (same files and dependency declarations; only the key order inside `.svforge-versions.json` differs, with identical checksums).
